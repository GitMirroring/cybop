
Add new CYBOL Operation
=======================

Kinds of CYBOL Operations
_________________________

Native cybol operation used with a mime type as e.g.:
calculate/add
communicate/send

Shell script operation incorporated into cybol as e.g.:
command/disk-free
command/grep

Processing Steps for Native CYBOL Operation
___________________________________________

* Write cybol example application using operation, which serves as test case
* Identify an operation name as well as necessary properties

* Add operation to file "include/constant/format/cybol/logic/*_logic_cybol_format.c" or add a new file
* Add cybol api description as comment above the new operation
* Add operation to file "include/constant/format/cyboi/logic_cyboi_format.c"
* Add file with cybol properties (options) for each new operation to directory "include/constant/name/cybol/logic/"

* Add operation to file "src/executor/representer/deserialiser/cybol/format_cybol_deserialiser.c"
* Add operation to file "src/executor/representer/serialiser/cybol/format_cybol_serialiser.c"

* Add file for each new operation to directory "src/executor/"
* Add file for each new operation to directory "src/applicator/"
* Add operation to file "src/controller/handler/operation_handler.c"

* Add function headers to "include/executor/*"
* Add file includes to "src/library/executor/*"
* Add function header to "include/applicator.h"
* Add file includes to "src/library/applicator_library.c"

Processing Steps for Shell Script Operation
___________________________________________

* Write cybol example application using operation, which serves as test case
* Identify an operation name as well as necessary properties

* Add operation to directory "constant/model/command/"
    -> go here to change names (if different for Unix/Win32)
* Add operation to file "constant/format/cybol/logic/command_logic_cybol_format.c"
* Add operation to file "constant/format/cyboi/logic_cyboi_format.c"
* Add file with cybol options for each new operation to directory "constant/name/cybol/logic/commander/"
    -> ALL options regardless of OS
* Add file with command options for each new operation to directory "constant/name/command_option/unix/" (or windows/)

* Add operation to file "executor/representer/deserialiser/cybol/format_cybol_deserialiser.c"
* Add operation to file "executor/representer/serialiser/cybol/format_cybol_serialiser.c"

* Add file for each new operation to directory "executor/commander/"
* Consider platform (unix or windows) using preprocessor defines

* Add file for each new operation to directory "applicator/command/"
    -> "remove_file.c" is a good example for this, since it has a parametre and options
* Add operation to section with comment "command" in file "controller/handler/operation_handler.c"
