1 Introduction
______________

The logic- and state formats available in cybol are documented in the
javadoc comment blocks of the respective constants in c source code.

A python script parses these documentation blocks automatically
and generates cybol files from them.

The cybol api generator then reads these cybol files and generates
an html website including css and some javascript functions.

2 Directory
___________

The python script needs to parse just ONE directory with constants:

constant/format/cybol/

3 Style
_______

The following two are taken as reference formats and are most up-to-date:

- for state: number/integer
- for logic: calculate/add

There are three possible sections in the comment block of a constant:

 * Description:
 * Examples:
 * Properties:

If there is no heading "Description:", then NOTHING gets generated.
The reason is that there are many constants without implementation.

All examples are copied 1:1 and written into just ONE file "examples.txt",
including possibly existing blank lines.

The properties are described using: name, required, format, description.
If the heading "Properties:" is missing, then a "properties.cybol" file
does NOT get generated.
