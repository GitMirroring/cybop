Eigentlich ist es ganz einfach:

Wenn du es ganz hart machen willst, dann werfe alle dinge mit
<code>
#ifdef PTW32_BUILD
# define PTW32_DLLPORT __declspec (dllexport)
#else
# define PTW32_DLLPORT __declspec (dllimport)
#endif
</code>

einfach raus (betrifft pthread.h, sched.h und semaphore.h)

Dafür musst Du nur ganz am anfang von pthread.h das folgende aufnehmen:
<code>
#define PTW32_DLLPORT
</code>


Jetzt làsst sich einfach der Typ des Projectes von DLL auf LIB
umstellen.

Wenn Du Die LIB linken möchtest musst Du natürlich darauf achten, dass
das gleiche Threading-Model verwendet wird (eingestellt ist per default
bei pthreads "Multithreaded-DLL").

Desweiteren muss Du die Init-Funktion, welche sonst in DllMain
aufgerufen wird direkt aufrufen:
<code>
pthread_win32_process_attach_np();
</code>

Dies natürlich bevor Du irgendwas mit pthreads machsts...

Wenn Du ein Beispielprojekt haben willst (aber VS2003), kann ich es Dir
gerne Mailen...
