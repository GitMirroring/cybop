Code Conventions

General Issues

  1. Use spaces and never tab characters
  2. Indent code by 4 spaces (editors offer to set indentation to 4 spaces)
  3. Make use of spaces and white lines to separate code logically
  4. Comment all code exhaustively

CYBOL

  2. Use only the one given tag (node) and four given attributes (name, channel, format, model)
  3. See examples: cybop/examples/
  4. See syntax: cybop/doc/books/cybol/syntax/
  5. See schema: cybop/doc/books/cybol/schema/

CYBOI

  1. Follow the C syntax
  2. Follow the Java Code Conventions (HTML | PDF)
  3. Document each function in JavaDoc style
  4. Consider the following exceptions, differing from Java Code Conventions
  5. Name all functions and variables in small letters
  6. Separate subwords with underscore
  7. Use the void return type, i.e. return nothing from a function
  8. Hand over all arguments/parametres as void pointer
  9. Define all unchangeable values (string, integer etc.) as constant in cybop/src/constant/
  10. Use data arrays together with their element count and size, no null-terminated strings
  11. Put the opening brackets to the end of a line, not on an extra line
  12. Check pointers for null before accessing them
  13. Use only if-else conditions, never switch-case statements
  14. Use only while loops, never do-while or for loops
  15. Use only endless loops and place the loop break condition inside the loop body
  16. Use only break conditions in a loop, never the continue keyword
  17. Example: 
        /**
     * This is an example procedure.
     *
     * It does nothing.
     *
     * @param p0 the first parametre is an integer
     * @param p1 the second parametre is a character
     * @param p2 the third parametre is a pointer, for example a char pointer (string)
     */
    void example_function(void* p0, void* p1, void* p2) {

        if (p2 != *NULL_POINTER_STATE_CYBOI_MODEL) {

            // Cast void pointer parametre to its actual type.
            wchar_t** s = (wchar_t**) p2;

            // Use the string by dereferencing s.
            fwprintf(stdout, L"The string value is: %ls\n", *s);

            if (p1 != *NULL_POINTER_STATE_CYBOI_MODEL) {

                // Cast void pointer parametre to its actual type.
                wchar_t* c = (wchar_t*) p1;

                // Use the character by dereferencing c.
                *c = 32;

                if (p0 != NULL_POINTER_STATE_CYBOI_MODEL) {

                    // Cast void pointer parametre to its actual type.
                    int* i = (int*) p0;

                    // Use the integer by dereferencing i.
                    *i = *i + 10;

                    // An example loop.
                    int j = *NUMBER_0_INTEGER_STATE_CYBOI_MODEL;

                    while (*TRUE_BOOLEAN_STATE_CYBOI_MODEL) {

                        if (j >= *NUMBER_10_INTEGER_STATE_CYBOI_MODEL) {

                            break;
                        }

                        j++;
                    }

                } else {

                    log_message_terminated((void*) ERROR_LEVEL_LOG_CYBOI_MODEL, (void*) L"Could not execute function. The parametre p0 is null.");
                }

            } else {

                log_message_terminated((void*) ERROR_LEVEL_LOG_CYBOI_MODEL, (void*) L"Could not execute function. The parametre p1 is null.");
            }

        } else {

            log_message_terminated((void*) ERROR_LEVEL_LOG_CYBOI_MODEL, (void*) L"Could not execute function. The parametre p2 is null.");
        }
    }
