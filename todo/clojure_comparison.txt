Main Characteristics of Functional Programming
______________________________________________

- immutable data (hash array mapped tries) -> thread-safe code
- recursion instead of loops (map, filter, reduce, fold)
- recursion instead of loops (first, second, last, rest)
- functions as arguments ("first class functions", "higher-order functions")

- uniform grammar of Lisp: every expression is a list,
  beginning with a verb, and followed by some arguments
  -> corresponds to cybol node for a logic operation

Clojure Disadvantages
_____________________

- special forms cannot be used as arguments to functions
- special forms implement core Clojure functionality that cannot be implemented with functions
- Macros are similar to special forms in that they evaluate
  their operands differently from function calls, and they
  also cannot be passed as arguments to functions
- special threading operators ->> and -> necessary to navigate through hierarchies
- Destructuring von Parametern entfällt in CYBOL (lokales Argument oder globaler Knowledge Tree ??),
  da alle Elemente als Baumknoten einen Namen haben

Innere Datenstruktur
____________________

- bei Aufruf einer Funktion wird Originalliste NICHT verändert (immutable)
- KEINE 1:1 Vollkopie der Datenstruktur (performance)

- alte und neue Datenstrukturen teilen sich die gemeinsamen Elemente
- bekannt als "structural sharing" or "shared structure"
- verwendete Datenstrukturen bezeichnet man als "Persistent Data Structures"
- Quelle:
https://www.heise.de/hintergrund/Clojure-Ein-pragmatisches-Lisp-fuer-die-JVM-1030144.html?seite=2

- flache Baum-Struktur zur Organisation der Dateninhalte
- besteht aus bis zu fünf Ebenen mit je 32 Werten
- beim Einfügen des 33. Werts wird eine neue Ebene erzeugt
- nutzt Java Integers a 32 Bit für Zugriff per Pfad
- zerlegen der 32 Bit in sechs Gruppen zu je fünf Bit
- jede Gruppe ist für den Index innerhalb einer Ebene zuständig
- benötigte 32 Werte für den Index in einem Knoten werden genau durch fünf Bits kodiert
- speicherbar sind bis zu 32^6 = 2^{30} Werte in einer Datenstruktur
- garantierter Zugriff auf persistente Datenstrukturen innerhalb von O(log_{32} N)
- Quelle:
https://www.heise.de/hintergrund/Parallelprogrammierung-mit-Clojure-1170690.html?seite=2
