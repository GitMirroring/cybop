        * Procedure to add a new cybol operation to cyboi:
            1. Write cybol example application using shell command (in order to identify an operation name as well as necessary properties)
            2. Add shell commands to directory "constant/model/command/" (NOT necessary for standard cybol operations) 
	      -> go here to change names (if different for Unix/Win32)
            3. Add commands to file "constant/format/cybol/logic/command_logic_cybol_format.c"
            4. Add commands to file "constant/format/cyboi/logic_cyboi_format.c"
            5. Add new file with options for each command and parameter to directory "constant/name/cybol/logic/commander/"
	      -> ALL commands regardless of OS
            6. Add new file with options for each command to directory "constant/name/command_option/unix/" (or windows/) (NOT necessary for standard cybol operations)
            7. Add commands to file "executor/representer/deserialiser/cybol/format_cybol_deserialiser.c" 
	      -> check file from step number 3
            8. Add commands to file "executor/representer/serialiser/cybol/format_cybol_serialiser.c"
            9. Add new file for each new command to directory "executor/commander/" (see example file "list_directory_contents_commander.c") 
	      -> check file from step number 2 for name of command, file from number 5 or number 6 for names of options
            10. Consider platform (unix or windows) using preprocessor defines
            11. Add new file for each command (cybol operation) to directory "applicator/command/"
	      -> remove_file.c is a good example for this - has parameter and options
            12. Add commands to section with comment "command" in file "controller/handler/operation_handler.c"
