How to Help

We currently follow the development model of "Benevolent Dictatorship". This is for historical reasons. Most contributions come from the project founder who implements ideas which he formulated over the years.

However, help from the Community is always welcome and could save time, which can then better be invested in developing the core interpreter. Here are some ideas where your support would be possible and useful:

  • CYBOL Editor (create development tool with several views: text, xml, json, tree-table, graphical blocks)
  • GUI Designer (develop RAD tool to create user interfaces quickly)
  • Documentation (write user manual and update API)
  • Website (maintain and update content)
  • Build Process (integrate libraries or factor out plug-ins, currently using cmake)
  • Continuous Integration/Delivery (package software for CI/CD)
  • Import/Export Filters (write parser and serialiser for new data formats)
  • Database Concept Integration (optimise JSON/XML file size for storage, provide SQL like queries)
  • Graphical User Interface (design GUI components, make use of fonts, implement layouts, control window)
  • Migration (port CYBOI interpreter to Windows, Mac OSX, Android, iOS)
  • CYBOL Library (provide basic functionality usable by CYBOL applications)
  • Bug Reporting (test cybol applications)
