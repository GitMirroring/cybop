Handbuch der CYBOL-Programmierung

access/count

Description

Counts the child nodes of a compound node of type "element/part" or "element/property".

Properties

name channel format model
add_integer inline calculate/add
| result inline text/cybol-path .result
| operand inline number/integer 2

Examples

<node name="add_integer" channel="inline" format="calculate/add" model=""> <node name="result" channel="inline" format="text/cybol-path" model=".result"/> <node name="operand" channel="inline" format="number/integer" model="2"/> </node>
